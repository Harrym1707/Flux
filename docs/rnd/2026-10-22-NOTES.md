## What happened tonight

1. Clean-clone setup (`corepack enable && pnpm install && pnpm build && pnpm test`):
   passed, 353/353 tests, no drift to report there.

2. Regression watch (`run-agent-ab.ts`, `run-cache-decomposition.ts`): **arm L —
   the eval that reproduces the published "sparse interactive 34.0%" number —
   hard-crashed** with `TTL stamp changed model-visible content at task 0 turn
   0; the stamp must be metadata-only.` That is exactly the guard it's supposed
   to be: it means the shipped cache-TTL stamp was changing what the model
   reads, not just where the cache breakpoint sits.

   Root cause: commit `ab210c1` ("Cache stamp can no longer lose money on a
   volatile prefix") added a stable/volatile-tail split for Anthropic system
   prompts — a real fix for a real measured loss — but the slice that finds
   the stable prefix dropped the newline that used to separate the stable text
   from the relocated tail (it sliced off `tailText.length + 1` chars instead
   of `tailText.length`). Anthropic concatenates adjacent system text blocks
   with no inserted separator, so every repaired multi-turn Anthropic request
   using `cacheTtl` was silently gluing the last stable character to the first
   tail character. `ab210c1` never touched `evals/run-agent-ab.ts`, so its own
   metadata-only control (`withoutStampArtifacts`) — which also never handled
   the two-block split shape, only ever flattened single-block systems — had
   nothing to catch this until tonight's run finally exercised arm L again.

   Fixed both: the one-character slice in
   `packages/sdk-js/src/reduce-request.ts` (`stampAnthropicCacheTtl`), and
   `withoutStampArtifacts` in `evals/run-agent-ab.ts` (now flattens N text
   blocks by concatenation, not just one). Hardened the test that was masking
   this in `cache-volatility-guard.test.ts`: it used to compare sorted lines
   after manually re-inserting a `\n`, which can't catch a dropped separator;
   it now asserts byte-exact string equality with no inserted separator, plus
   a new case with a two-line moved tail. 354 tests pass.

   Numbers that depend on this code path move on honest remeasurement:
   cache-only 37.6% → 37.9%, full-stack-vs-raw 57.1% → 57.3%, sparse-interactive
   (arm L) 34.0% → 34.3% (this one was flat-out unreproducible, not just
   drifted, until tonight's fix). `README.md` and `docs/site/evidence.md`
   updated to match, with provenance. Async-net 57.7% and one-shot 45.5%
   reproduced exactly, no drift.
