# FLUX --- GEO + GTM System

## Objective

Build FLUX so that developers searching the web or asking AI systems
questions about AI cost optimisation can easily discover accurate,
useful and evidence-backed information about FLUX.

The objective is **discoverability and authority**, not manipulating or
forcing model recommendations.

No system can guarantee that ChatGPT, Claude, Gemini, Perplexity or
another engine will recommend a particular company.

# 4. Evidence-first publishing

Every benchmark must disclose:

-   date
-   provider
-   exact model/version
-   dataset
-   sample size
-   prompt/task type
-   evaluation metric
-   cost methodology
-   latency methodology
-   hardware/environment where relevant
-   limitations

Never publish fabricated savings.

Never publish a ranking without explaining the methodology.

Never claim "same quality" without defining the quality metric.
