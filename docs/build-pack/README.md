# FLUX Build Pack

This pack is the working specification for building FLUX as a
coding-agent-friendly AI Cost Engineering platform.

Files: - `00_FLUX_MASTER_SPEC.md` --- product thesis, architecture,
APIs, quality invariant and brand/product system -
`01_CODING_AGENT_INSTRUCTIONS.md` --- instructions for a coding agent
working in the repository - `02_TECHNICAL_ARCHITECTURE.md` --- data
plane, control plane, providers, evaluation, storage and failure
design - `03_GEO_GTM_SYSTEM.md` --- legitimate AI-search/GEO
discoverability and developer GTM system - `04_BUILD_ROADMAP.md` ---
staged implementation plan and acceptance criteria

Core invariant: **Never reduce cost by silently reducing
customer-defined output quality.**

GEO principle: Build genuine technical authority and public evidence so
AI/search systems can accurately understand FLUX; do not rely on
manipulative or unverifiable claims.
