# FLUX hook and brand: 2026-10-28 (draft)

Status: draft for the founder. Nothing here is published.

## The brief

Caveman won attention with a hook you can repeat after reading it once ("why use many token when few
token do trick"), a mascot (a rock), one-line install and slash commands. FLUX needs the same
loudness in its own voice: flow, flux, cutting the bill. It has one constraint Caveman doesn't. FLUX
bills from its numbers, so every figure in the marketing must be one already in `docs/NUMBERS.md`,
with its LIVE or SIMULATOR label within reach.

## Five candidate taglines

1. **Stop paying twice for the same tokens.** (chosen)
2. **Cut the bill, not the brain.**
3. **Same answers. Smaller bill. Receipt included.**
4. **Go with the flow. Pay for less of it.**
5. **One URL between you and a smaller bill.**

### Why #1 wins

- **It's true at the mechanism level.** That matters because we bill from it. An agent that never
  opts into the prompt cache re-buys its whole history at full rate every turn: our first live export
  measured zero cache traffic on a five-turn agent. Exact-duplicate removal literally deletes tokens
  you were about to pay for twice. The line names the problem FLUX fixes, not a vibe.
- **It holds up when someone pushes back.** "Twice? Show me." The answer is the ledger. #2 and #4 are
  catchier on first read but don't point at anything you can check.
- **It works alongside Caveman.** Caveman's joke is about how many words the agent uses. Ours is about
  how many times you pay for them. Different layers, so "use both" is natural, not a stretch.
- **It's short enough for the nav, an X bio, an OG title and a plugin description.** It's already in
  all four.

Runners-up and where to use them: #2 is the X/meme line ("Caveman cuts the words. FLUX cuts the bill,
not the brain."). #3 goes under the hero CTA on Product Hunt. #4 is for stickers and swag only (too
soft for a headline). #5 is the developer-docs subhead.

## Mascot and visual concept: "Dam", the beaver

- **Who:** a flat, two-colour beaver in the existing FLUX palette (Midnight `#102A43`, Ocean
  `#2864A5`, Sky Signal `#9DD9F5`). Its tail is the FLUX wave mark from the favicon, so the mascot and
  the logo are the same drawing.
- **Why a beaver:** FLUX means flow. A beaver doesn't stop the river. It controls how much gets
  through, using material that's already there. That's the product: the request still flows and the
  answers stay the same, but the waste stays behind the dam. Caveman carries a rock. Dam carries a
  **receipt**.
- **Running visual gag:** Dam holding a long, curling till receipt (the landing page's receipt slip,
  with its torn zig-zag edge). In every appearance the receipt shows a real line from a committed
  ledger. It's never a made-up number, because the receipt is the joke and the proof at once.
- **Copy voice:** short, dry and a bit smug about maths. "Dam checked. You paid for that prefix five
  times." "Dam says: do not pay us." (the 0–5% verdict, used proudly).
- **Where it goes first:** the README hero (once drawn), the plugin's directory icon (512 px square
  PNG; `claude plugin validate` currently warns ICON_MISSING), the OG image, and Product Hunt
  gallery slide 1.
- **Not yet drawn.** No asset is committed. Commission it as a single SVG plus a 512 px PNG.

## Number rules for anyone writing in this voice

Lead with the biggest real figure, keep its label, and link NUMBERS.md:

| Say | Label it | NUMBERS.md row |
|---|---|---|
| up to 72.8% | one-shot templated traffic that can wait (simulator) | `45.5% / 72.8%` One-shot templated traffic (two arms), arms H/I |
| 38.1% | a coding agent, live API traffic | per-agent line under the 18.2% live row |
| 18.2% | net, 30 live requests, real money | `18.2%` CURRENT headline live number |
| 37.9% | Claude's cache lever alone (simulator) | `37.9%` Multi-turn Claude cache lever ALONE vs cache-off |
| 0–5% | "do not pay us" | Reference numbers: `0–5%` |

Never: user counts, star counts, testimonials, "average customer saves", or any percentage that isn't
in that file.
